# Book API

A simple RESTful Book API built with **Node.js** and **Express.js**. This project demonstrates the basic concepts of Express, routing, middleware, route parameters, and CRUD operations using an in-memory data array.

## Features

* Express.js web server
* RESTful API routes
* GET all books
* GET a single book by ID
* POST a new book
* PUT/update an existing book
* DELETE a book
* JSON request and response handling
* Simple 404 error handling

## Technologies Used

* **Node.js**
* **Express.js**
* **JavaScript**
* **REST API**
* **JSON**

## Project Structure

After completing the setup, your project should look like this:

```text
book-api/
│
├── server.js
├── package.json
└── package-lock.json
```

> **Important:** Do **not** manually create `package.json` or `package-lock.json`. These files are automatically generated by npm when you run the setup commands below.

## Installation

### 1. Create the project folder

```bash
mkdir book-api
cd book-api
```

### 2. Initialize the Node.js project

Run:

```bash
npm init -y
```

This command automatically creates the:

```text
package.json
```

file.

### 3. Install Express

Run:

```bash
npm install express
```

This command installs Express and automatically creates or updates:

```text
package.json
package-lock.json
```

It also creates the `node_modules` folder.

Your project should now contain:

```text
book-api/
│
├── node_modules/
├── server.js
├── package.json
└── package-lock.json
```

### 4. Create `server.js`

You only need to manually create the **`server.js`** file.

Copy the provided Book API code into `server.js`.

## Running the API

Start the server with:

```bash
node server.js
```

You should see:

```text
Server running on http://localhost:3000
```

Open the following URL in your browser:

```text
http://localhost:3000
```

You should see:

```text
Welcome to the Book API
```
